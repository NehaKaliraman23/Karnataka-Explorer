# Karnataka-Explorer
An AI-powered travel planner for Karnataka

An AI-powered travel planner that creates personalized travel itineraries for Karnataka, India.

## Problem Statement
Planning a trip requires time and effort to choose destinations, organize daily activities, estimate expenses, and find locations.

## Our Solution
Karnataka Explorer helps travellers generate personalized travel plans using AI based on their preferences and available time.

## Features
- AI-generated travel itineraries
- Travel planning based on interests and trip duration
- Estimated travel budget in the generated plan
- Google Maps links for destinations
- Downloadable travel plans
- Simple and user-friendly interface

## Technology Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

## Setup Instructions

1. Clone or download this repository.
2. Install Node.js.
3. Install project dependencies:

   npm install

4. Create a `.env` file in the project root.
5. Add your Gemini API key:

   GEMINI_API_KEY=your_api_key_here

6. Start the application using the start command configured in `package.json`.

## Security
Keep API keys in environment variables. Never upload your `.env` file or expose secret API keys publicly.
